# NEON RACER

Современная браузерная аркадная игра на HTML, CSS и JavaScript без сторонних игровых библиотек.

## Запуск на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Для разработки удобнее открыть папку в VS Code и запустить `index.html` через расширение Live Server.

## Управление

- `←` / `→` или `A` / `D` — менять полосу.
- На телефоне используйте экранные кнопки.
- Собирайте монеты и избегайте машин.
- Лучший результат сохраняется в `localStorage` этого браузера.

## Публикация на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и нажмите **New repository**.
2. Назовите репозиторий, например `neon-racer`. Для простоты выберите **Public**.
3. Создайте репозиторий.
4. Нажмите **Add file → Upload files** и загрузите `index.html`, `style.css`, `script.js` и `README.md` в корень репозитория.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В блоке **Build and deployment** выберите **Deploy from a branch**.
8. В качестве ветки выберите `main`, папку — `/(root)`, затем нажмите **Save**.
9. Подождите минуту или несколько минут. Ссылка появится в разделе Pages и будет примерно такой:
   `https://ВАШ-ЛОГИН.github.io/neon-racer/`

Если обновили файлы, загрузите изменения и снова нажмите **Commit changes** — GitHub Pages опубликует обновлённую версию автоматически.

## Файлы

- `index.html` — структура страницы и элементы интерфейса.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — игровая логика, отрисовка трассы, трафик, монеты, столкновения и рекорды.
